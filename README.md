## 💫 About Me

I'm a **frontend & full-stack developer** who turns ideas into fast, polished and scalable web experiences — from pixel-perfect, animation-rich interfaces to secure APIs, databases and live deployments.

- 🎨 I build **premium, responsive, animation-rich frontends** with React, Next.js (App Router), Tailwind CSS and Framer Motion
- ⚙️ I build **REST APIs and backends** with Node.js, Express, Sequelize and MySQL
- 🚀 I deploy and manage apps on **VPS / Linux servers** and on Vercel & Netlify
- 🏢 I've delivered projects across **real estate, interior design, automotive, healthcare/ambulance, hospitality, NGO and media** industries, as well as SaaS/ERP products
- 🧠 Currently sharpening my **DSA & problem-solving** skills
- 📫 Open to freelance work, collaborations and full-time opportunities
